# Welcome to deckd

A self-contained deck-building service with an MCP server.

---

# Edit this deck

- Open it in the deckd web app, or point an MCP client at `/mcp`.
- Slides split on a line containing exactly three hyphens.
- This deck's theme comes from `theme.css` in this bundle.

---

# Build your own bundle

Replace `theme.css` and this `presentations/` directory with your own,
then point `DECKD_BUNDLE_DIR` at your bundle (or upload it via
`/admin.html`).
